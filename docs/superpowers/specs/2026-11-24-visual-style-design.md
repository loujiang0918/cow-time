# Cow Time 视觉风格设计（滚动数字与背景风格）

- 日期：2026-11-24
- 状态：已确认并实现（2026-11-24）
- 基础版本：[Cow Time 悬浮窗设计](2026-11-24-cow-time-design.md)（功能已实现并验收）

## 1. 目标

改进悬浮窗的观感，做两件事：

1. 金额数字按位滚动。
2. 背景风格可以在设置里选择，共四种：素色、极光、霓虹、星空。

范围：只改前端页面，以及与它直接相关的配置项和校验。薪资计算、假期、窗口位置、单实例等逻辑保持不变。

## 2. 数字滚动

「本月已赚」和「今日已赚」两处金额使用里程表式的滚动数字。

- 每一位数字是一条竖直的纸带，上面依次是 0 到 9。数字变化时纸带向上移动，停在新的数字上。
- 只有发生变化的位才滚动，没有变化的位保持不动。发生进位时，几位同时滚动，例如 `.19` 变成 `.21`。
- 从 9 到 0 时经过 0 继续向上滚到目标数字。
- 一次滚动在 0.28 秒内完成。金额每秒更新一次，所以每一位每秒最多滚动一次。
- 每一位的宽度固定（等宽数字），滚动时整个数字不会左右抖动。
- 数值的位数发生变化时（例如从 `999.99` 变成 `1,000.00`），直接显示新的位数，不做动画。
- 尚未设置月薪时，两处金额显示 `--`。
- 「距元旦 38 天」里的天数保持普通文字。

## 3. 背景风格

背景作用在整个窗口卡片上，显示视图和设置视图使用同一种风格。窗口是逐像素透明的，卡片底色是半透明的，后面的桌面内容会清晰地透出来。

| 风格 | 设置里的名字 | 配置里的值 | 卡片底色 | 卡片里的元素 | 动画 |
|---|---|---|---|---|---|
| 素色 | 素色 | `plain` | `rgba(24, 24, 30, 0.72)` | 无 | 无 |
| 极光 | 极光 | `aurora` | `rgba(10, 12, 26, 0.40)` | 青、紫、粉三个柔和的光团 | 光团缓慢平移并缩放，周期分别是 13、17、11 秒，往复循环 |
| 霓虹 | 霓虹 | `neon` | `rgba(4, 6, 18, 0.68)` | 一圈 2 像素宽的彩色描边，卡片内侧有辉光 | 描边的颜色沿边缘流动，7 秒转一圈 |
| 星空 | 星空 | `stars` | `rgba(7, 9, 24, 0.58)` | 一片星云，28 颗大小不同的星星 | 星云缓慢漂移，20 秒一个往复；每颗星星闪烁并向上飘，周期在 1.6 到 4.2 秒之间 |

- 默认风格是极光。
- 素色就是现在的外观：卡片底色、文字颜色、内描边都保持原样。
- 四种风格下文字都保持清晰：标签用半透明的浅色，数字带与风格搭配的阴影或光晕。霓虹风格下数字是带冷光的白色。数字的光晕加在整个数字上。
- 三种带动画的风格只使用页面的 CSS 动画，动画区域是 240×132 的卡片。

## 4. 设置视图

```
 设置                                  ✕
 月薪                          [ 10000 ]
 上班时间                      [ 09:00 ]
 午休开始                      [ 12:00 ]
 午休结束                      [ 13:00 ]
 下班时间                      [ 18:00 ]
 背景风格            [素色] 极光  霓虹  星空
                           [ 取消 ]  [ 保存 ]
```

- 新增「背景风格」一行，是四个并排的单选按钮：素色、极光、霓虹、星空。选中的按钮高亮。
- 背景风格和月薪、作息一起保存：点「保存」才生效，点「取消」恢复成保存之前的风格。
- 选择过程中，设置视图的卡片立即按选中的风格显示，可以直接看到效果。
- 第一次启动时也可以选择，随月薪一起保存。
- 设置视图的窗口尺寸从 240×300 DIP 变为 240×336 DIP。放不下时向上展开的规则不变。

## 5. 配置与接口

配置文件 `%APPDATA%\cow-time\config.json` 增加一项：

```json
{
  "monthlySalary": 10000,
  "workHours": { "start": "09:00", "lunchStart": "12:00", "lunchEnd": "13:00", "end": "18:00" },
  "backgroundStyle": "aurora",
  "window": { "x": 1664, "y": 972 }
}
```

- `backgroundStyle` 的取值是 `plain`、`aurora`、`neon`、`stars` 之一。
- 配置里没有这一项，或者值不是这四个之一时，按 `aurora` 处理，月薪、作息、窗口位置等其他配置照常生效。

Go 侧的改动：

- `config.Config` 增加 `BackgroundStyle` 字段，默认值是 `aurora`。读取配置时把不认识的值换成默认值。
- `config` 包提供 `ValidBackgroundStyle(style)`，判断取值是否是四个合法值之一。读取配置和保存设置时共用它。
- `service.Settings` 增加 `backgroundStyle` 字段。`SaveSettings` 发现取值不合法时保存失败，提示「背景风格无效」。
- `GetStatus` 返回的 `settings` 里带有 `backgroundStyle`，前端用它显示当前的背景，并用来填充设置视图。
- `wingeo.SettingsHeight` 从 300 改为 336。

## 6. 异常处理

| 情况 | 处理 |
|---|---|
| 配置里没有 `backgroundStyle`，或者值不认识 | 按极光显示，其他配置照常生效 |
| 保存设置时 `backgroundStyle` 不合法 | 保存失败，提示「背景风格无效」，原来的设置保持不变 |
| 金额的位数发生变化 | 直接显示新的位数，不做动画 |
| 前端拿到的风格值没有对应的样式 | 按极光显示 |

## 7. 测试

**Go 单元测试**

- `internal/config`：没有 `backgroundStyle` 时取默认值；不认识的值换成默认值，且月薪、作息保持不变；合法的值读写往返一致。
- `internal/service`：`SaveSettings` 接受四个合法值并写入配置；拒绝不合法的值，且原有设置不变；`GetStatus` 返回的 `settings` 带有 `backgroundStyle`。
- `internal/wingeo`：设置视图变高之后，「向上展开」的几个用例仍然成立。

**前端**

前端没有自动化测试，按下面的方式核对：

1. 构建之后分别截图四种风格，检查显示视图和设置视图的排版、文字清晰度、数字与标点的对齐。
2. 用界面自动化走一遍：在设置里选一种风格并保存，重启之后风格保持；选另一种后点取消，风格恢复。
3. 核对滚动数字：工作时间内金额每秒滚动，变化的位向上滚，没有变化的位不动。

**手动检查清单**（需要用户确认）

1. 四种风格的观感，以及在真实桌面上的通透程度。
2. 在设置里逐个点击四种风格，设置视图立即切换。
3. 保存后回到显示视图，风格是刚才选的那一种；点取消则恢复原样。
4. 金额滚动时的观感：自然、不抖、不刺眼。
5. 设置视图变高之后，贴着任务栏时仍然向上展开。

## 8. 不在本次范围内

动画强弱的开关、更多的背景风格、跟随系统的深色和浅色模式。

## 9. 实现记录（2026-11-24）

改动的文件：

- `internal/config/config.go`：`BackgroundStyle` 字段、四个取值的常量、`DefaultBackgroundStyle`、`ValidBackgroundStyle`。读取配置时把缺失或不认识的值换成默认值。
- `internal/service/service.go`：`Settings.BackgroundStyle`。`SaveSettings` 校验并保存背景风格，`GetStatus` 返回它。
- `internal/wingeo/wingeo.go`：`SettingsHeight` 改为 336。
- `frontend/index.html`、`frontend/style.css`、`frontend/main.js`：滚动数字、四种背景风格、设置视图里的「背景风格」一行。
- `internal/config/config_test.go`、`internal/service/service_test.go`、`internal/wingeo/wingeo_test.go`：对应的测试。

验证结果：

- Go 单元测试：6 个包、62 个用例全部通过，其中新增 `TestValidBackgroundStyle` 和 `TestLoadBackgroundStyle`。
- 构建正式版之后实际运行并截图核对：四种风格的显示视图和设置视图都正常。
- 用界面自动化走了一遍：在设置里选风格时立即预览，点取消后恢复，点保存后写入配置，重启之后保持。
- 连拍确认：金额变化时只有发生变化的数字位在滚动。

补充（2026-11-25）：窗口背景类型从 `BackgroundTypeTranslucent`（系统的亚克力磨砂）改为 `BackgroundTypeTransparent`（逐像素透明），`BackdropType` 设置随之删除。

原因：系统的磨砂背景铺满整个矩形窗口，而页面的圆角只能裁掉页面自己绘制的那一层，所以圆角外面会露出一圈没有加深色底色的磨砂长方形。

另外比较过「保留磨砂、让系统把窗口裁成圆角」的做法：圆角会变成系统的 8 像素，并且四周带一条系统的细边线和一圈系统阴影，长方形的框并没有完全消失。

验证：构建之后放大截图确认，圆角外面的区域完全透明，没有长方形，也没有边线。
