# Cow Time 背景透明度滑块的设计

- 日期：2026-11-25
- 状态：已确认并实现（2026-11-25 用户确认范围为 0 到 100，并要求拖动时直接生效、不需要点保存）
- 基础版本：[Cow Time 悬浮窗设计](2026-11-24-cow-time-design.md)、[视觉风格设计](2026-11-24-visual-style-design.md)

## 1. 目标

背景的透明程度可以在设置里用滑块调节。拖动时立即看到效果，并且立即保存。

## 2. 设置界面

```
 背景风格                       [素色] 极光  霓虹  星空
 透明度          [==========|-----]   28%
```

- 设置视图在「背景风格」下面多一行「透明度」：一个滑块，右边显示当前的百分比。
- 设置视图的窗口尺寸从 240×392 DIP 变为 240×428 DIP。

## 3. 行为

- 透明度的范围是 0 到 100，单位是百分比。0% 表示卡片底色完全不透明，100% 表示卡片底色完全透明。
- 透明度只影响卡片的底色。文字、数字，以及各种风格自带的装饰（极光的光团、霓虹的描边、星空的星云）不受影响。
- 滑块调节的是设置视图里当前选中的背景风格。四种风格各有一个透明度，切换风格时滑块跳到那一种风格的值。

| 背景风格 | 初始透明度 |
|---|---|
| 素色 | 28% |
| 极光 | 60% |
| 霓虹 | 32% |
| 星空 | 42% |

- 拖动滑块时，卡片底色立即变化。
- 停止拖动约 0.2 秒之后，透明度自动写入配置文件。它不需要点「保存」。
- 「取消」和「保存」都不影响透明度：透明度在拖动时就已经保存。
- 第一次启动、还没有设置月薪时，也可以直接调节透明度。

## 4. 保存方式

配置里新增一项 `transparency`，只记录与初始值不同的风格：

```json
"transparency": { "plain": 10 }
```

- 键是背景风格的值，值是 0 到 100 之间的整数。
- 没有记录的风格使用初始值。
- 某一种风格的透明度被调回初始值之后，它的记录被删除。

## 5. 前端与 Go 的接口

**新增 `SetTransparency(style, value)`**：立即把某种背景风格的透明度写入配置。`style` 是背景风格的值，`value` 是 0 到 100 的整数。成功时返回 `ok`，失败时返回原因。

**`GetStatus()`** 的返回值里增加 `transparency`：四种风格各自生效的透明度，单位是百分比。

**`SaveSettings(settings)`** 不涉及透明度。保存月薪、作息、背景风格时，已经保存的透明度保持不变。

## 6. 校验与异常

| 情况 | 处理 |
|---|---|
| 调用 `SetTransparency` 时，风格不是四种背景风格之一 | 不保存，返回「背景风格无效」 |
| 调用 `SetTransparency` 时，透明度不在 0 到 100 之间 | 不保存，返回「透明度需要在 0% 到 100% 之间」 |
| 配置里 `transparency` 的键不是四种背景风格之一 | 忽略这一项，那一种风格没有记录 |
| 配置里 `transparency` 的值超出 0 到 100 | 忽略这一项，那一种风格使用初始值 |
| Go 拒绝了一次透明度保存 | 滑块回到这次拖动之前的值，并在设置视图里显示原因 |

### 修复（2026-11-25）：滑块能保存数值，但卡片的透明度不变

上面第一次验证只确认了数值被保存、滑块显示的数字正确，没有检查卡片的颜色是否变化。实际上卡片的透明度完全没有变。

用像素取样确认了问题：素色风格下，透明度取 0、100 和初始值时，卡片空白处的颜色完全相同，都是底色和桌面按 40% / 60% 混合的结果。

原因：`.widget` 自己声明了 `--card-alpha: 0.4`。元素自己声明的自定义变量优先于从 `body` 继承来的值，所以 `main.js` 写在 `body` 上的值被挡住了。副作用是所有风格的底色都固定为 40% 不透明，比设计值更透。

修复：删掉 `.widget` 上的声明。初始值只写在 `var(--card-alpha, 初始值)` 的回退位置。

修复之后用像素取样验证，取样点是卡片上方留白的中点：

| 背景风格 | 透明度 0 | 透明度 100 |
|---|---|---|
| 素色 | `rgb(24,24,30)`，等于底色 | `rgb(236,236,238)`，等于桌面 |
| 极光 | `rgb(18,57,74)` | `rgb(197,234,241)` |
| 霓虹 | `rgb(9,23,42)` | `rgb(218,231,240)` |
| 星空 | `rgb(15,41,72)` | `rgb(195,219,240)` |

素色在透明度 28% 时是 `rgb(83,83,88)`，在 60% 时是 `rgb(152,152,155)`，都与按比例混合的计算结果一致。在设置视图里连续改滑块，卡片颜色同步变化。

回归测试：`internal/service/stylesheet_test.go` 检查样式表没有声明 `--card-alpha`，并且 `main.js` 把它写在 `body` 上。

仍然没有验证到的部分：用鼠标真正拖动滑块。自动化是直接设置滑块的值。
